## Project Overview

This is an ESP32-based IoT health monitoring system that measures heart rate and SpO2 (blood oxygen saturation) using a MAX30105 sensor, then publishes the data to AWS IoT Core via MQTT. The system consists of two main components:

1. **Firmware** (`firmware/`): ESP32 Arduino code for sensor data collection and AWS communication
2. **Infrastructure** (`terraform/`): AWS infrastructure as code for IoT Core, DynamoDB, and CloudWatch

## Architecture

### Data Flow
1. ESP32 reads raw IR/Red signals from MAX30105 sensor
2. Firmware applies smoothing algorithm to reduce noise (10-sample moving average)
3. Valid readings (HR: 40-180 bpm, SpO2: 70-100%) are published to AWS IoT Core
4. AWS IoT Topic Rule routes data to:
   - DynamoDB table for persistent storage
   - CloudWatch metrics for monitoring/dashboards

### Key Components

**Firmware** (`firmware/src/main.cpp`):
- Uses sliding window approach: collects 100 samples initially, then processes 25 new samples at a time
- Implements smoothing to filter invalid readings
- Maintains persistent MQTT connection with auto-reconnect
- Uses certificates from `secrets.h` (generated by Terraform)

**AWS Infrastructure**:
- IoT Thing + Certificate authentication
- IoT Policy for publish/subscribe permissions
- DynamoDB table with composite key (device_id, timestamp)
- IoT Topic Rule subscribes to `health/monitor` topic
- CloudWatch metrics for real-time monitoring

## Development Commands

### Firmware Development

**Build the firmware:**
```bash
cd firmware
pio run
```

**Upload to ESP32:**
```bash
pio run --target upload
```

**Monitor serial output:**
```bash
pio device monitor
```

**Build and upload in one command:**
```bash
pio run --target upload && pio device monitor
```

**Important Notes:**
- Upload port is configured as `/dev/ttyUSB0` in `platformio.ini` - adjust if your ESP32 is on a different port
- Serial monitor baud rate is 115200
- The firmware expects `secrets.h` to exist (generated by Terraform)

### Infrastructure Management

**Initialize Terraform:**
```bash
cd terraform
terraform init
```

**Create `terraform.tfvars` file:**
```bash
cat > terraform.tfvars << EOF
wifi_ssid     = "YourWiFiSSID"
wifi_password = "YourWiFiPassword"
EOF
```

**Preview infrastructure changes:**
```bash
terraform plan
```

**Apply infrastructure:**
```bash
terraform apply
```

**Destroy infrastructure:**
```bash
terraform destroy
```

**Important Notes:**
- Terraform generates `firmware/src/secrets.h` with WiFi credentials and AWS endpoint
- After running `terraform apply`, you'll receive certificate files - keep these secure
- The generated `secrets.h` file is gitignored and must be regenerated if lost

## Configuration Details

### Sensor Configuration
Located in `firmware/src/main.cpp:130-136`:
- LED Brightness: 60
- Sample Average: 4
- LED Mode: 2 (Red + IR)
- Sample Rate: 100 Hz
- Pulse Width: 411 μs
- ADC Range: 4096

### MQTT Topic
- Default topic: `health/monitor`
- Can be changed in `terraform/main.tf:75`

### Device ID
- Hardcoded as `ESP32_01` in `firmware/src/main.cpp:103`
- Modify this line if deploying multiple devices

### Data Validation Thresholds
Located in `firmware/src/main.cpp:41-42`:
- Valid heart rate: 40-180 bpm
- Valid SpO2: 70-100%
- Finger detection threshold: IR value > 50000
